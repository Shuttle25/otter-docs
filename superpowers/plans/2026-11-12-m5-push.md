# M5 — Push notifications (FCM), version label, publish-safe repos — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A message wakes a sleeping phone (screen off, app not open) through a data-less FCM push and shows a
notification «Мама: Купи хлеб» within 5 s. Without Google services, or when FCM turns out not to work, the app falls
back to «Экономия батареи» (a check every 15 min). Settings shows the app version at the bottom. Both repositories are
safe to publish on the internet. **Done when:** a message wakes phone A (screen off, idle) and shows a notification
in < 5 s on FCM; automated tests use a fake FCM server; the battery-saver fallback shows a notification within 15 min on
an emulator without working FCM.

**Architecture:**
- *Nodes:* a phone registers its FCM token with a signed `PUSH_TOKEN` record (`push.register`), which replicates like
  every record; the newest per (user, device) wins. When an **urgent** envelope is stored for a recipient who has **no
  live session on this node**, the node that is responsible (D58) sends one data-only, high-priority FCM message through
  the FCM HTTP v1 API, authenticated with a Firebase service-account key (`/etc/otter/fcm.json`, optional). At most one
  push per recipient per 10 s per node. A token FCM reports as unregistered is dropped.
- *App:* one build (no foss flavor). `firebase-messaging` is always a dependency; the `google-services` Gradle plugin is
  applied only when `app/google-services.json` exists (the file is never committed), so the build works without it and
  simply has no push. A push starts an expedited WorkManager job that holds a "wake" lease on the `SyncEngine`
  (connect — last-good endpoint alone for 2 s, then race — drain the mailbox, run the outbox, stop after 10 s idle, at
  most 60 s). Incoming visible messages post MessagingStyle notifications per chat. A `PushMonitor` decides the mode:
  «Быстрые уведомления» (FCM) or «Экономия батареи» (periodic 15-min WorkManager sync).
- *Repos:* `.gitignore` covers every private file; a pinned gitleaks scan of the full history runs in both repos;
  rewriting the author e-mail of existing commits is owner-gated (Task 1).

**Decisions (made by the planner; Task 13 records them as D57–D63 in `docs/00-decisions.md`):**
- **D57 Publish-safe repositories:** never in git: `google-services.json`, `fcm*.json`, `*.jks`, `*.keystore`,
  `keystore.properties`, `.env*`, the admin dir (`~/.otter-admin`, outside the repos anyway), `.dev-mesh/`, `.vm/`,
  `dist/`, `local.properties`. `scripts/secrets-check.sh` (both repos) runs gitleaks **v8.24.0** over the whole history
  plus a grep for private IPs (`192.168.`, `10.`, the VPS address), `/home/`, and e-mail addresses other than
  `noreply` ones. Test vectors are allowlisted by path in `.gitleaks.toml`. Rewriting existing commits' author e-mail is
  done only with the owner's explicit OK (bundle backup first).
- **D58 Who pushes:** on a record accepted **locally** (client submit): this node pushes if it is push-capable. On a
  record **replicated from peer P**: this node pushes only if P is not push-capable **and** this node is the first
  push-capable node in manifest order (P is the best available approximation of the origin; in a full mesh it is the
  origin). "Push-capable" = the manifest says `push_capable` **and** this node has an FCM key loaded. Push only when the
  envelope is `urgent`, created ≤ 10 min ago, and the recipient (user, device) has no live, non-replaced session on this
  node. Coalescing: ≤ 1 push per (user, device) per 10 s per node.
- **D59 FCM message and key:** FCM HTTP v1 `messages:send` with `{"token", "android": {"priority": "HIGH",
  "collapse_key": "otter", "ttl": "600s"}, "data": {"w": "1"}}` — a constant payload, no ids, no content. OAuth2 via
  `golang.org/x/oauth2/google.JWTConfigFromJSON` (scope `https://www.googleapis.com/auth/firebase.messaging`),
  project id read from the key file. Key file `/etc/otter/fcm.json` (0640 root:otter); the node.toml template always
  names it under `[push] fcm_credentials`, and a **missing file means push is off** (so re-installing a bundle never
  breaks or removes push). Installed only by `deploy/push-key.sh`; never in bundles, the admin dir or git.
  404/`UNREGISTERED` → the node deletes that token row locally; other errors are logged.
- **D60 PUSH_TOKEN record:** payload `PushToken{device_id = 1, kind = FCM, token ≤ 4096 bytes}` signed by the account
  key, sent via `push.register` (RecordRequest). Apply: newest `created_ms` per (user, device) wins (ties by record key).
  Records never expire (one per token change). The app re-sends only when the token differs from the last one a node
  accepted.
- **D61 Background model on the phone:** `SyncEngine` runs while at least one lease is held — `foreground` (app
  visible, existing behaviour) or `wake` (push / battery-saver job). A wake job: lease → race with a 2 s head start for
  the last-good endpoint → stop when online and no envelope event for 10 s and the outbox has nothing due (cap 60 s).
  Expedited `OneTimeWorkRequest` (`RUN_AS_NON_EXPEDITED_WORK_REQUEST` when out of quota; on API 26–30 it runs as a
  `dataSync` foreground service with a silent «Проверяем сообщения…» notification). Mode: **FAST** when Google Play
  services + Firebase are available, a token exists and fewer than 3 "missed wake-ups" in 24 h; else **SAVER** (unique
  periodic work every 15 min with a network constraint). A missed wake-up = in one session the phone receives an
  envelope created after the previous session ended, at least 60 s before this session started, and no FCM wake arrived
  since that envelope was created. Any FCM wake clears the misses.
- **D62 Notifications:** channels «Сообщения» (direct) and «Группы» (IMPORTANCE_HIGH) and «Синхронизация»
  (IMPORTANCE_MIN, for the API < 31 foreground job). One MessagingStyle notification per conversation (id =
  conversation id) with the last 6 unread messages (photo → «Фото», caption appended), grouped under one summary;
  actions «Ответить» (RemoteInput → outbox) and «Прочитано» (mark read + read receipts); tap opens the chat.
  `VISIBILITY_PRIVATE` + public version «Otter» / «Новое сообщение». No notification for the chat open on screen;
  cleared when the chat is read. In-app switch «Показывать уведомления» (default on). POST_NOTIFICATIONS asked once
  (Android 13+) the first time the chat list is shown.
- **D63 App version:** `versionName = "0.5.0"`, `versionCode = 5`; Settings shows «Otter 0.5.0 (abc1234)» at the very
  bottom, below «Подключение»; the short git hash comes from a Gradle `providers.exec` (`"dev"` when not a git checkout).

**Tech Stack:** as M6, plus server `golang.org/x/oauth2 v0.30.0` (`google` + `jwt`); Android
`com.google.firebase:firebase-bom:34.0.0` (`firebase-messaging`), Gradle plugin `com.google.gms.google-services:4.4.3`,
`androidx.work:work-runtime-ktx:2.10.1` (+ `work-testing`), `androidx.hilt:hilt-work:1.3.0` + `androidx.hilt:hilt-compiler:1.3.0`

**Out of scope:** «Мгновенно» (persistent foreground connection), a Google-free build flavor, call notifications,

```go
package push

import (
	"context"
	"errors"
	"fmt"
	"log/slog"
	"sync"
	"time"
)

// Sender delivers one wake-up to an FCM token.
type Sender interface {
	Send(ctx context.Context, token string) error
}

// Tokens is the store side (internal/store implements it).
type Tokens interface {
	PushToken(ctx context.Context, user []byte, device uint32) (string, error)
	DropPushToken(ctx context.Context, user []byte, device uint32, token string) error
}

// Pusher wakes devices: ≤ 1 push per (user, device) per Every (D58). Sends run in the background.
type Pusher struct {
	Every time.Duration
	Now   func() time.Time

	sender Sender
	tokens Tokens
	log    *slog.Logger
	mu     sync.Mutex
	last   map[string]time.Time
	wg     sync.WaitGroup
}

func New(sender Sender, tokens Tokens, log *slog.Logger) *Pusher {
	return &Pusher{Every: 10 * time.Second, Now: time.Now, sender: sender, tokens: tokens, log: log, last: map[string]time.Time{}}
}

// Wake implements service.Waker.
func (p *Pusher) Wake(ctx context.Context, user []byte, device uint32) {
	k := fmt.Sprintf("%x/%d", user, device)
	now := p.Now()
	p.mu.Lock()
	if t, ok := p.last[k]; ok && now.Sub(t) < p.Every {
		p.mu.Unlock()
		return
	}
	p.last[k] = now
	for key, t := range p.last { // keep the map small
		if now.Sub(t) > time.Minute {
			delete(p.last, key)
		}
	}
	p.mu.Unlock()
	p.wg.Add(1)
	go func() {
		defer p.wg.Done()
		ctx, cancel := context.WithTimeout(context.WithoutCancel(ctx), 20*time.Second)
		defer cancel()
		tok, err := p.tokens.PushToken(ctx, user, device)
		if err != nil || tok == "" {
			return
		}
		switch err := p.sender.Send(ctx, tok); {
		case err == nil:
			p.log.Debug("push sent", "user", fmt.Sprintf("%x", user))
		case errors.Is(err, ErrUnregistered):
			p.log.Info("push token unregistered: dropped", "user", fmt.Sprintf("%x", user))
			_ = p.tokens.DropPushToken(ctx, user, device, tok)
		default:
			p.log.Warn("push failed", "err", err)
		}
	}()
}

// Wait blocks until in-flight sends finish (tests, shutdown).
func (p *Pusher) Wait() { p.wg.Wait() }
```

```go
// pushMaxAge: an envelope older than this (a late replication) never triggers a push.
const pushMaxAge = 10 * time.Minute

func capable(m *pb.Manifest, id []byte) bool {
	for _, n := range m.Nodes {
		if bytes.Equal(n.NodeId, id) {
			return n.PushCapable
		}
	}
	return false
}

// pushDuty implements D58: from == nil for a record a client submitted here, else the peer it came from.
func (s *Service) pushDuty(from []byte) bool {
	m := s.CurrentManifest()
	if s.Waker == nil || m == nil || !capable(m, s.NodeID) {
		return false
	}
	if from == nil {
		return true
	}
	if capable(m, from) {
		return false // the origin (approximated by the sending peer) pushes itself
	}
	for _, n := range m.Nodes {
		if n.PushCapable {
			return bytes.Equal(n.NodeId, s.NodeID)
		}
	}
	return false
}

// maybePush wakes offline recipients of an urgent envelope this node is responsible for.
func (s *Service) maybePush(ctx context.Context, body *pb.RecordBody, from []byte) {
	if body.CreatedMs < s.Now().Add(-pushMaxAge).UnixMilli() || !s.pushDuty(from) {
		return
	}
	var e pb.Envelope
	if proto.Unmarshal(body.Payload, &e) != nil || !e.Urgent {
		return
	}
	for _, r := range e.Recipients {
		if !s.Notify.Online(r.User, r.Device) {
			s.Waker.Wake(ctx, r.User, r.Device)
		}
	}
}
```

```kotlin
package app.ottermsg.core.data.push

import app.ottermsg.core.data.Clock
import app.ottermsg.core.data.settings.Settings
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.combine
import javax.inject.Inject
import javax.inject.Singleton

enum class PushMode { FAST, SAVER }

/** D61: FCM ("Быстрые уведомления") while it demonstrably works, else the 15-min battery saver. */
@Singleton
class PushMonitor @Inject constructor(private val settings: Settings, private val clock: Clock) {
    @Volatile private var missSession = -1L

    suspend fun mode(): PushMode = modeOf(settings.pushAvailable(), settings.pushToken(), recent(settings.pushMisses()))

    fun observeMode(): Flow<PushMode> = combine(settings.observePushAvailable(), settings.observePushToken(),
        settings.observePushMisses()) { a, t, m -> modeOf(a, t, recent(m)) }

    /** An FCM wake-up arrived: FCM works. */
    suspend fun onWake() {
        settings.setPushLastWakeMs(clock.now())
        settings.setPushMisses(emptyList())
    }

    /** The engine went fully offline (no lease left). */
    suspend fun onOffline() = settings.setLastOfflineMs(clock.now())

    /** Envelopes created at [createdMs] were delivered in session [sessionId] that logged in at [sessionStartMs]. */
    suspend fun onDelivered(createdMs: List<Long>, sessionStartMs: Long, sessionId: Long) {
        if (sessionId == missSession) return
        val offlineSince = settings.lastOfflineMs()
        if (offlineSince == 0L) return
        val lastWake = settings.pushLastWakeMs()
        val missed = createdMs.any { it > offlineSince && it > lastWake && sessionStartMs - it >= LATE_MS }
        if (!missed) return
        missSession = sessionId
        val now = clock.now()
        settings.setPushMisses((settings.pushMisses() + now).filter { now - it < DAY_MS })
    }

    private fun recent(m: List<Long>): Int { val now = clock.now(); return m.count { now - it < DAY_MS } }

    companion object {
        const val DAY_MS = 86_400_000L
        const val LATE_MS = 60_000L
        const val MAX_MISSES = 3
        fun modeOf(available: Boolean, token: String?, misses: Int): PushMode =
            if (available && !token.isNullOrEmpty() && misses < MAX_MISSES) PushMode.FAST else PushMode.SAVER
    }
}
```

```kotlin
import app.ottermsg.core.crypto.RecordCodec
import app.ottermsg.core.data.Clock
import app.ottermsg.core.data.account.AccountRepository
import app.ottermsg.core.data.settings.Settings
import app.ottermsg.core.network.NodeApi
import app.ottermsg.proto.v1.PushToken
import app.ottermsg.proto.v1.RecordType
import kotlinx.coroutines.sync.Mutex
import kotlinx.coroutines.sync.withLock
import javax.inject.Inject
import javax.inject.Singleton

/** Sends this device's FCM token as a signed PUSH_TOKEN record when it changed (D60). It replicates to every node. */
@Singleton
class PushRegistrar @Inject constructor(
    private val accounts: AccountRepository, private val settings: Settings, private val clock: Clock,
) {
    private val mutex = Mutex()

    suspend fun registerIfNeeded(api: NodeApi) = mutex.withLock {
        val token = settings.pushToken() ?: return@withLock
        if (token == settings.pushTokenSent()) return@withLock
        val me = accounts.require()
        val payload = PushToken.newBuilder().setDeviceId(1).setKind(PushToken.Kind.FCM).setToken(token).build()
        api.registerPush(RecordCodec.sign(RecordCodec.body(RecordType.PUSH_TOKEN, me.userId, payload.toByteArray(),
            createdMs = clock.now()), me.accountKey))
        settings.setPushTokenSent(token)
    }
}
```

```kotlin
package app.ottermsg.core.data.push

import app.ottermsg.core.data.Clock
import app.ottermsg.core.data.sync.SyncEngine
import app.ottermsg.core.network.ConnectionState
import kotlinx.coroutines.delay
import kotlinx.coroutines.flow.first
import kotlinx.coroutines.withTimeoutOrNull
import javax.inject.Inject
import javax.inject.Singleton

/** One background wake (D61): connect, drain the mailbox, flush the outbox, go offline after [IDLE_MS] of quiet. */
@Singleton
class BackgroundSync @Inject constructor(
    private val engine: SyncEngine, private val monitor: PushMonitor, private val clock: Clock,
) {
    suspend fun drain(fromPush: Boolean, maxMs: Long = MAX_MS, idleMs: Long = IDLE_MS): Boolean {
        if (fromPush) monitor.onWake()
        engine.startWake()
        try {
            return withTimeoutOrNull(maxMs) {
                engine.connection.first { it is ConnectionState.Online }
                while (clock.now() - engine.lastActivityMs < idleMs || engine.outboxHasDue()) delay(POLL_MS)
                true
            } ?: false
        } finally {
            engine.release(SyncEngine.WAKE) // the FOREGROUND lease (if the app became visible) keeps it running
        }
    }

    companion object { const val MAX_MS = 60_000L; const val IDLE_MS = 10_000L; const val POLL_MS = 500L }
}
```

```kotlin
    private val active: ActiveConversation, private val visibility: AppVisibility,

    override suspend fun onIncoming(conversationId: Long) {
        if (!settings.notificationsEnabled() || !permitted()) return
        if (visibility.visible && active.id == conversationId) return
        val conv = db.conversationDao().get(conversationId) ?: return
        val unread = db.messageDao().unreadReceiptsPending(conversationId)
        if (unread.isEmpty()) return
        val names = unread.map { it.senderId }.distinctBy { it.toHexKey() }
            .associate { id -> id.toHexKey() to (db.contactDao().get(id)?.displayName ?: conv.title) }
        val group = conv.type == ConversationType.GROUP
        val content = NotificationContent.build(conv.title, group, unread, names, context.getString(R.string.notif_photo))
        if (content.lines.isEmpty()) return
        post(conversationId, content)
    }

    override fun onRead(conversationId: Long) {
        nm.cancel(conversationId.toInt())
        if (nm.activeNotifications.none { it.groupKey?.endsWith(GROUP) == true && it.id != SUMMARY_ID }) nm.cancel(SUMMARY_ID)
    }

    private fun permitted() = Build.VERSION.SDK_INT < 33 ||
        ContextCompat.checkSelfPermission(context, Manifest.permission.POST_NOTIFICATIONS) == PackageManager.PERMISSION_GRANTED

        val me = Person.Builder().setName(context.getString(R.string.notif_me)).build()
        val style = NotificationCompat.MessagingStyle(me).setConversationTitle(if (c.group) c.title else null).setGroupConversation(c.group)
        c.lines.forEach { style.addMessage(it.text, it.timeMs, Person.Builder().setName(it.sender).build()) }
        val channel = if (c.group) Channels.GROUPS else Channels.MESSAGES
        val open = PendingIntent.getActivity(context, cid.toInt(),
            Intent(context, MainActivity::class.java).setAction(ACTION_OPEN).putExtra(EXTRA_CONVERSATION, cid)
                .addFlags(Intent.FLAG_ACTIVITY_NEW_TASK or Intent.FLAG_ACTIVITY_CLEAR_TOP),
            PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE)
        val reply = NotificationCompat.Action.Builder(0, context.getString(R.string.notif_reply),
            actionIntent(cid, NotificationActionReceiver.ACTION_REPLY, mutable = true))
            .addRemoteInput(RemoteInput.Builder(NotificationActionReceiver.KEY_TEXT).setLabel(context.getString(R.string.notif_reply_hint)).build())
            .setSemanticAction(NotificationCompat.Action.SEMANTIC_ACTION_REPLY).setShowsUserInterface(false).build()
        val read = NotificationCompat.Action.Builder(0, context.getString(R.string.notif_mark_read),
            actionIntent(cid, NotificationActionReceiver.ACTION_READ, mutable = false))
            .setSemanticAction(NotificationCompat.Action.SEMANTIC_ACTION_MARK_AS_READ).setShowsUserInterface(false).build()
        val public = NotificationCompat.Builder(context, channel).setSmallIcon(R.drawable.ic_stat_otter)
```

```kotlin
package app.ottermsg.notify

import android.content.BroadcastReceiver
import android.content.Context
import android.content.Intent
import androidx.core.app.RemoteInput
import app.ottermsg.core.data.di.ApplicationScope
import app.ottermsg.core.data.messaging.MessageRepository
import app.ottermsg.push.WakeScheduler
import dagger.hilt.android.AndroidEntryPoint
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.launch
import javax.inject.Inject

@AndroidEntryPoint
class NotificationActionReceiver : BroadcastReceiver() {
    @Inject lateinit var messages: MessageRepository
    @Inject lateinit var wake: WakeScheduler
    @Inject @ApplicationScope lateinit var scope: CoroutineScope

    override fun onReceive(context: Context, intent: Intent) {
        val cid = intent.getLongExtra(MessageNotifier.EXTRA_CONVERSATION, -1)
        if (cid < 0) return
        val pending = goAsync()
        scope.launch {
            try {
                if (intent.action == ACTION_REPLY) {
                    val text = RemoteInput.getResultsFromIntent(intent)?.getCharSequence(KEY_TEXT)?.toString().orEmpty()
                    if (text.isNotBlank()) messages.sendText(cid, text)
                }
                messages.markConversationRead(cid) // also cancels the notification (MessageAlerts.onRead)
                wake.wakeNow() // deliver the reply / read receipts without opening the app
            } finally { pending.finish() }
        }
    }

    companion object {
        const val ACTION_REPLY = "app.ottermsg.REPLY"
        const val ACTION_READ = "app.ottermsg.MARK_READ"
        const val KEY_TEXT = "text"
    }
}
```

```kotlin
package app.ottermsg.push

import android.content.Context
import androidx.work.*
import app.ottermsg.core.data.push.PushMode
import dagger.hilt.android.qualifiers.ApplicationContext
import java.util.concurrent.TimeUnit
import javax.inject.Inject
import javax.inject.Singleton

@Singleton
class WakeScheduler @Inject constructor(@ApplicationContext private val context: Context) {
    private val wm get() = WorkManager.getInstance(context)

    /** A push arrived (or a notification action needs the network): one expedited drain. */
    fun wakeNow(fromPush: Boolean = false) {
        wm.enqueueUniqueWork(WAKE, ExistingWorkPolicy.KEEP, OneTimeWorkRequestBuilder<WakeWorker>()
            .setExpedited(OutOfQuotaPolicy.RUN_AS_NON_EXPEDITED_WORK_REQUEST)
            .setInputData(workDataOf(WakeWorker.FROM_PUSH to fromPush)).build())
    }

    /** D61: the 15-min battery saver runs only in SAVER mode. */
    fun apply(mode: PushMode) {
        if (mode == PushMode.SAVER) {
            wm.enqueueUniquePeriodicWork(SAVER, ExistingPeriodicWorkPolicy.KEEP,
                PeriodicWorkRequestBuilder<SaverWorker>(15, TimeUnit.MINUTES)
                    .setConstraints(Constraints.Builder().setRequiredNetworkType(NetworkType.CONNECTED).build()).build())
        } else wm.cancelUniqueWork(SAVER)
    }

    companion object { const val WAKE = "wake"; const val SAVER = "saver" }
}
```

```kotlin
@HiltWorker
class WakeWorker @AssistedInject constructor(
    @Assisted context: Context, @Assisted params: WorkerParameters, private val sync: BackgroundSync,
) : CoroutineWorker(context, params) {
    override suspend fun doWork(): Result {
        sync.drain(fromPush = inputData.getBoolean(FROM_PUSH, false))
        return Result.success() // a failed drain is retried by the next push / saver run / app start
    }

    override suspend fun getForegroundInfo(): ForegroundInfo {
        val n = NotificationCompat.Builder(applicationContext, Channels.SYNC).setSmallIcon(R.drawable.ic_stat_otter)
            .setContentText(applicationContext.getString(R.string.notif_sync_text)).setSilent(true).build()
        return if (Build.VERSION.SDK_INT >= 29) ForegroundInfo(NOTIF_ID, n, ServiceInfo.FOREGROUND_SERVICE_TYPE_DATA_SYNC)
        else ForegroundInfo(NOTIF_ID, n)
    }

    companion object { const val FROM_PUSH = "from_push"; const val NOTIF_ID = Int.MAX_VALUE - 2 }
}
```

```kotlin
@AndroidEntryPoint
class OtterMessagingService : FirebaseMessagingService() {
    @Inject lateinit var settings: Settings
    @Inject lateinit var registrar: PushRegistrar
    @Inject lateinit var engine: SyncEngine
    @Inject lateinit var wake: WakeScheduler
    @Inject @ApplicationScope lateinit var scope: CoroutineScope

    override fun onNewToken(token: String) {
        scope.launch {
            settings.setPushToken(token)
            engine.current()?.let { api -> runCatching { registrar.registerIfNeeded(api) } }
        }
    }

    /** The payload is a constant (D59): any message means "you have mail". */
    override fun onMessageReceived(message: RemoteMessage) = wake.wakeNow(fromPush = true)
}
```

```kotlin
data class NotificationsUi(val mode: PushMode, val enabled: Boolean)

@HiltViewModel
class NotificationsViewModel internal constructor(
    mode: Flow<PushMode>, enabled: Flow<Boolean>, private val save: suspend (Boolean) -> Unit,
) : ViewModel() {
    @Inject constructor(monitor: PushMonitor, settings: Settings) :
        this(monitor.observeMode(), settings.observeNotificationsEnabled(), settings::setNotificationsEnabled)

    val ui: StateFlow<NotificationsUi?> = combine(mode, enabled) { m, e -> NotificationsUi(m, e) }
        .stateIn(viewModelScope, SharingStarted.Eagerly, null)

    fun setEnabled(v: Boolean) { viewModelScope.launch { save(v) } }

@Composable
fun NotificationsRoute(onBack: () -> Unit, vm: NotificationsViewModel = hiltViewModel()) {
    val ui by vm.ui.collectAsStateWithLifecycle()
    val context = LocalContext.current
    val systemOn = remember { NotificationManagerCompat.from(context).areNotificationsEnabled() }
    Scaffold(containerColor = MaterialTheme.colorScheme.background,
        topBar = { OtterTopBar(stringResource(R.string.settings_notifications), onBack = onBack) }) { padding ->
        val u = ui ?: return@Scaffold
```
