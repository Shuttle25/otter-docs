# M6.5 — Otter news (signed announcements) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The owner sends a news message from the PC (`otter-admin announce`, or the dialog at the end of a release)
and every member sees it as an ordinary message from «Выдра» / "Otter" in the chat «Новости Выдры» / "Otter News",
optionally with an «Обновить» button that downloads the new APK **from the Otter nodes**, checks its SHA-256 and opens
the Android installer. **Done when:** `otter-admin announce` on the PC → the news appears on FCM phones within seconds
(within 15 min in battery-saver mode); a record signed by any other key, or by a revoked key, is rejected by nodes
and apps (meshsim + unit tests); «Обновить» downloads the APK from a node, rejects a wrong hash and installs a
correct one.

**Architecture:**
- *Keys:* a dedicated Ed25519 **news key** lives in the owner's desktop keyring (GNOME Secret Service, via
  `github.com/zalando/go-keyring`). Its public key is listed in the manifest (`Manifest.news_keys`, signed by the admin
  key as usual). Removing it from the manifest revokes it: nodes and phones drop everything it signed.
- *Records:* `ANNOUNCEMENT` (texts RU/EN, optional app update) and `ANNOUNCEMENT_DELETED` (target record key), both
  authored by `ID16(news pub)` and signed by the news key. Not end-to-end encrypted (nodes can read them). Kept
  forever; replicated like every record. `otter-admin` publishes each one to **every** node directly
  (`news.publish`, public method, like `manifest.publish`).
- *Delivery:* phones call `news.list` after login (all announcements + deletions — few and small) and again on the
  `news` event. A node that accepts a new announcement wakes every push-registered device that is not online (D58
  duty rule, coalescing as in M5).
- *APK:* `deploy/release-apk.sh` copies the APK to every node (`otter-node apk import`, kept in
  `/var/lib/otter/apk/<sha256>.apk`, newest 2). Phones download it over their pinned connection with `apk.get`
  (1 MiB chunks), check size + SHA-256, then open the system installer. All APKs are signed with a new **release
  keystore** (owner's PC, gitignored).
- *App:* announcements are verified (signature + key in the stored manifest) and stored as ordinary rows: one
  conversation with `type = NEWS`, messages with `kind = NEWS` (`body` = text in the phone's language for previews and
  notifications; `system_data` = the `Announcement` bytes for rendering). No composer, no receipts.

**Tech stack:** Go 1.24 (server, admin), protobuf, SQLite; `github.com/zalando/go-keyring` **v0.2.6**; bash deploy
scripts (Android SDK `apksigner` + `aapt2`); Kotlin, Room, Hilt, Compose (app).

**Decisions (made by the planner; Task 13 records them as D64–D69 in `docs/00-decisions.md`):**
- **D64 News, not a service account:** a real account would need a headless Signal client holding keys, one
  encrypted copy per member, no history for later members and no verifiable update. Announcements are signed, not
  E2E encrypted; release notes only. On the phone they are ordinary messages from «Выдра» / "Otter" in an ordinary
  (not pinned) chat «Новости Выдры» / "Otter News".
- **D65 News key:** Ed25519, generated by `otter-admin news init`, stored in the Secret Service keyring (service
  `ottermsg-news`, account `network-<first 8 bytes of network_pub, hex>`, value = base64 of the 32-byte seed); the
  public key is appended to `~/.otter-admin/news_keys.json` and goes into `Manifest.news_keys` at the next
  `manifest sign`. A record is valid only while its author key is in the **current** manifest. `news revoke` removes
  the key; on the next manifest, nodes delete every announcement/deletion it authored and phones delete the messages.
  Claude never asks for or stores a passphrase; the admin passphrase is typed by the owner in the terminal.
- **D66 Records:** `ANNOUNCEMENT = 15` payload `Announcement{text_ru, text_en, update?}`; each text ≤ 4000 runes,
  valid UTF-8, at least one non-blank; `expires_ms = 0`; `update = AppUpdate{version_name (1..32 chars),
  version_code > 0, sha256 (32 bytes), size (1..100 MiB)}`. `ANNOUNCEMENT_DELETED = 16` payload
  `AnnouncementDeleted{target}` (record key author‖id, 32 bytes), signed by any current news key. A node keeps the
  deletion forever (table `news_deleted`) so a lagging peer cannot resurrect the announcement. Delete only, no edit.
  A replicated record whose news key is not in this node's manifest is **skipped** (not retried: a revoked key would
  stall the peer session forever); the admin publishes to every node directly, so no node misses one.
- **D67 Delivery & push:** `news.list` (logged in) → `RecordBatch` of every stored ANNOUNCEMENT and
  ANNOUNCEMENT_DELETED, oldest first; event `news` (`Empty`) to every logged-in session when one is accepted or
  dropped. On a newly accepted ANNOUNCEMENT created ≤ 10 min ago the node wakes, under the D58 duty rule, every
  (user, device) with a push token that has no live session here; deletions never push. Phones notify only for
  announcements created within the last 3 days (a new member does not get a notification storm), at most one
  notification update per `news.list`.
- **D68 APK on the nodes:** `otter-node apk import FILE` copies the file into `<data_dir>/apk/<sha256 hex>.apk`
  (owner = data dir owner, 0640) and keeps the newest 2. `apk.get{sha256, index}` (logged in) → `ApkChunk{data,
  total_size}`, 1 MiB chunks; unknown hash or index past the end → NOT_FOUND. The app downloads to
  `cacheDir/apk/<hex>.part` (resumes at full-chunk boundaries), checks size and SHA-256, renames to `.apk`, opens the
  installer through a FileProvider; a mismatch deletes the file and shows «Файл повреждён». «Обновить» shows only if
  `update.version_code` > the installed versionCode. Every release APK is signed with the release keystore
  (`otter-android/keystore.properties` + `*.jks`, gitignored); `release-apk.sh` refuses a debug-signed APK.
- **D69 Release dialog, language, links:** `deploy/news-dialog.sh VERSION [--apk FILE --version-code N]` reads
  `dist/news/<VERSION>.md` (sections `## ru`, `## en`; written by Claude during the release session from the
  commits), shows each language and asks «[о]тправить / [и]зменить / [п]ропустить» (edit opens `$EDITOR`), then
  asks for a final confirmation and runs `otter-admin announce`. `upgrade-all.sh` and `release-apk.sh` call it at
  the end when run from a terminal (`--no-news` skips). The phone shows Russian when its language is `ru`, otherwise
  English, otherwise whichever text exists. http/https URLs in the text are tappable; a tap shows the full address and
  asks «Открыть ссылку?» before the browser opens.

**Versions:** server **0.6.0** (eeee runs 0.5.0), app **0.6.0** (versionCode 6).

**Branches:** `m6-5-news` in both repos (Task 1 creates them). Commit trailers: see the session's attribution rules.

```go
	News NewsResolver // nil: announcements are rejected

// signerKey: before `default:`

	case pb.RecordType_ANNOUNCEMENT_DELETED:

			return ErrBadPayload

func checkAnnouncement(b *pb.RecordBody) error {
	var a pb.Announcement
	if err := proto.Unmarshal(b.Payload, &a); err != nil || b.ExpiresMs != 0 {
		return ErrBadPayload
	}
	text := func(s string) bool {
		return utf8.ValidString(s) && utf8.RuneCountInString(s) <= MaxNewsText
	}

		return ErrBadPayload
	}

			u.Size == 0 || u.Size > MaxBlobSize {
			return ErrBadPayload
		}
	}
	return nil
}
```

```go
		out = append(out, raw)
	}

// DropNewsExcept deletes announcements and deletions whose author is not in keep (revoked news keys, D65).
func (s *Store) DropNewsExcept(ctx context.Context, keep [][]byte) (int, error) {
	n := 0
	err := s.write(ctx, func(ctx context.Context, tx *sql.Tx) error {
		q := `DELETE FROM records WHERE type IN (?,?)`
		args := []any{int32(pb.RecordType_ANNOUNCEMENT), int32(pb.RecordType_ANNOUNCEMENT_DELETED)}
		if len(keep) > 0 {
			q += ` AND author NOT IN (` + strings.TrimSuffix(strings.Repeat("?,", len(keep)), ",") + `)`
			for _, k := range keep {
				args = append(args, k)
			}
		}
		res, err := tx.ExecContext(ctx, q, args...)
		if err != nil {
			return err
		}
		c, _ := res.RowsAffected()
		n = int(c)
		return nil
	})
	return n, err
}
```

```go
func (s *Service) NewsKey(id []byte) (ed25519.PublicKey, bool) {

		return nil, false
	}
	for _, k := range m.NewsKeys {

	}

func isNews(t pb.RecordType) bool {
	return t == pb.RecordType_ANNOUNCEMENT || t == pb.RecordType_ANNOUNCEMENT_DELETED
}

// PublishNews accepts an announcement or a deletion sent by the admin (news.publish, D67). Idempotent.
func (s *Service) PublishNews(ctx context.Context, rec *pb.Record) error {
	body, err := s.validator(nil).Validate(rec)
	if errors.Is(err, records.ErrUnknownNewsKey) {
		return fmt.Errorf("%w: news key not in the manifest — run manifest sign and manifest publish", ErrInvalid)
	}
	if err != nil {
		return invalid(err)
	}
	if !isNews(body.Type) {
		return fmt.Errorf("%w: not an announcement", ErrInvalid)
	}
	_, applied, err := s.Store.ApplyFrom(ctx, rec, body, s.NodeID)
	if err == nil && applied {
		s.afterApply(ctx, body, nil)
	}
	return err
}

// News returns every stored announcement and deletion, oldest first (news.list).
func (s *Service) News(ctx context.Context) ([]*pb.Record, error) {
	raws, err := s.Store.News(ctx)
	if err != nil {
		return nil, err
	}
	out := make([]*pb.Record, 0, len(raws))
	for _, raw := range raws {
		r := &pb.Record{}
		if err := proto.Unmarshal(raw, r); err != nil {
			return nil, err
		}
		out = append(out, r)
	}
	return out, nil
}

// dropRevokedNews deletes news authored by keys no longer in the manifest (D65).
func (s *Service) dropRevokedNews(ctx context.Context) {
	m := s.CurrentManifest()
	if m == nil {
		return
	}
	var keep [][]byte
	for _, k := range m.NewsKeys {
		keep = append(keep, keys.ID16(k))
	}
	n, err := s.Store.DropNewsExcept(ctx, keep)
	if err != nil {
		s.Log.Warn("dropping revoked news failed", "err", err)
		return
	}
	if n > 0 {
		s.Log.Info("revoked news dropped", "records", n)

	}
```

```go
// Import copies src into the directory under its SHA-256 and prunes old files. Returns the sum.
func (d *Dir) Import(src string) ([]byte, error) {
	in, err := os.Open(src)
	if err != nil {
		return nil, err
	}
	defer in.Close()
	tmp, err := os.CreateTemp(d.path, ".import-*")
	if err != nil {

	h := sha256.New()
	if _, err := io.Copy(io.MultiWriter(tmp, h), in); err != nil {
		tmp.Close()
		return nil, err
	}

		return nil, err
	}
	sum := h.Sum(nil)
	dst := filepath.Join(d.path, hexName(sum))
	if err := os.Chmod(tmp.Name(), 0o640); err != nil {
		return nil, err
	}
	if st, err := os.Stat(filepath.Dir(d.path)); err == nil && os.Geteuid() == 0 {

			_ = os.Chown(d.path, int(sys.Uid), int(sys.Gid))
		}
	}
	if err := os.Rename(tmp.Name(), dst); err != nil {
		return nil, err
	}
	d.prune()
	return sum, nil
}

// prune keeps the Keep newest APK files.
func (d *Dir) prune() {
	files, _ := filepath.Glob(filepath.Join(d.path, "*.apk"))
	if len(files) <= Keep {
		return
	}
	type f struct {
		p string
		t int64
	}
	var all []f
	for _, p := range files {
		if st, err := os.Stat(p); err == nil {
			all = append(all, f{p, st.ModTime().UnixNano()})
		}
	}
	sort.Slice(all, func(i, j int) bool { return all[i].t > all[j].t })
	for _, x := range all[Keep:] {
		os.Remove(x.p)
	}
}

// Chunk returns chunk index of the file with this SHA-256 and the file size.
// A missing file or an index past the end returns an error wrapping os.ErrNotExist.
func (d *Dir) Chunk(sum []byte, index uint32) ([]byte, uint64, error) {
	if len(sum) != sha256.Size {
		return nil, 0, fmt.Errorf("bad sum: %w", os.ErrNotExist)
	}
	f, err := os.Open(filepath.Join(d.path, hexName(sum)))
	if err != nil {
		return nil, 0, err
	}
	defer f.Close()
	st, err := f.Stat()
	if err != nil {
		return nil, 0, err
	}
	off := int64(index) * ChunkSize
	if off >= st.Size() {
		return nil, 0, fmt.Errorf("chunk %d: %w", index, os.ErrNotExist)
	}
	buf := make([]byte, min(ChunkSize, st.Size()-off))
	if _, err := f.ReadAt(buf, off); err != nil && err != io.EOF {
		return nil, 0, err
	}
	return buf, uint64(st.Size()), nil
}
```

```go
		return nil, nil
```

```kotlin
package app.ottermsg.core.crypto

import app.ottermsg.proto.v1.Announcement
import app.ottermsg.proto.v1.AnnouncementDeleted
import app.ottermsg.proto.v1.Record
import app.ottermsg.proto.v1.RecordBody
import app.ottermsg.proto.v1.RecordType
import com.google.protobuf.InvalidProtocolBufferException

/** A verified news record (D66). [key] = record key author ‖ id. */
sealed interface News {
    val key: ByteArray; val author: ByteArray; val createdMs: Long
    class Item(override val key: ByteArray, override val author: ByteArray, override val createdMs: Long, val announcement: Announcement) : News
    class Deleted(override val key: ByteArray, override val author: ByteArray, override val createdMs: Long, val target: ByteArray) : News
}

object AnnouncementVerifier {
    /** Verifies [record] against the news keys of the stored manifest; null if it is not a valid news record. */
    fun verify(record: Record, newsKeys: List<ByteArray>): News? = try {
        val body = RecordBody.parseFrom(record.body)
        val author = body.author.toByteArray()
        val pub = newsKeys.firstOrNull { it.size == 32 && Ids.id16(it).contentEquals(author) }
        when {
            pub == null || !RecordCodec.verify(record, pub) -> null
            body.type == RecordType.ANNOUNCEMENT -> {
                val a = Announcement.parseFrom(body.payload)
                if ((a.textRu + a.textEn).isBlank()) null else News.Item(author + body.id.toByteArray(), author, body.createdMs, a)
            }
            body.type == RecordType.ANNOUNCEMENT_DELETED -> {
                val t = AnnouncementDeleted.parseFrom(body.payload).target.toByteArray()
                if (t.size != 32) null else News.Deleted(author + body.id.toByteArray(), author, body.createdMs, t)
            }
            else -> null
        }
    } catch (e: InvalidProtocolBufferException) { null }
}
```

```kotlin
package app.ottermsg.core.data.news

@Singleton
class NewsRepository @Inject constructor(
    private val db: OtterDatabase, private val keys: NewsKeys, private val clock: Clock, private val alerts: MessageAlerts,
) {
    private val mutex = Mutex()

    /** news.list → local messages (D67). */
    suspend fun sync(api: NodeApi) = apply(api.newsList())

    suspend fun apply(records: List<Record>) = mutex.withLock {
        val newsKeys = keys.newsKeys()
        val now = clock.now()
        var notify: Long? = null
        for (r in records) {
            when (val n = AnnouncementVerifier.verify(r, newsKeys)) {
                is News.Item -> {
                    val a = n.announcement
                    val cid = db.conversationDao().getOrCreateNews(now)
                    val id = db.messageDao().insert(MessageEntity(messageId = n.key, conversationId = cid, senderId = n.author,
                        outgoing = false, sentMs = n.createdMs, receivedMs = now,
                        body = NewsText.pick(a.textRu, a.textEn, Locale.getDefault().language),
                        status = MessageStatus.DELIVERED /* use the status MailboxReceiver gives incoming messages */,
                        kind = MessageKind.NEWS, systemData = a.toByteArray()))
                    if (id > 0) {
                        db.conversationDao().touch(cid, n.createdMs)
                        db.conversationDao().incrementUnread(cid)
                        if (n.createdMs > now - NOTIFY_WINDOW_MS) notify = cid
                    }
                }
                is News.Deleted -> db.messageDao().deleteNews(n.target)
                null -> log.info("news record ignored (unknown or revoked key, or malformed)")
            }
        }
        fixUnread()
        notify?.let { alerts.onIncoming(it) }
    }

    /** After a manifest update: drop news of keys no longer listed (D65). */
    suspend fun purgeRevoked() = mutex.withLock {
        val allowed = keys.newsKeys().map { Ids.id16(it).toHexKey() }.toSet()
        for (m in db.messageDao().allNews()) if (m.senderId.toHexKey() !in allowed) db.messageDao().deleteNews(m.messageId)
        fixUnread()
    }

    /** unread never exceeds the number of news messages left. */
    private suspend fun fixUnread() {
        val c = db.conversationDao().news() ?: return
        val left = db.messageDao().count(c.id)
        if (c.unread > left) { db.conversationDao().clearUnread(c.id); repeat(left.coerceAtMost(c.unread)) { db.conversationDao().incrementUnread(c.id) } }
    }

    companion object {
        const val NOTIFY_WINDOW_MS = 3 * 86_400_000L
        private val log = Logger.getLogger("NewsRepository")
    }
}
```

```kotlin
// ApkUpdater.kt
package app.ottermsg.core.data.news

sealed interface UpdateResult {
    data class Ready(val file: File) : UpdateResult
    data object Corrupt : UpdateResult
    data object NotOnServer : UpdateResult
    data object Offline : UpdateResult
}

@Singleton
class ApkUpdater @Inject constructor(private val online: OnlineApi, @param:CacheDir private val cacheDir: File) {
    suspend fun download(u: AppUpdate, progress: (Float) -> Unit): UpdateResult = withContext(Dispatchers.IO) {
        val hex = u.sha256.toByteArray().toHex()
        val dir = File(cacheDir, "apk").apply { mkdirs() }
        val done = File(dir, "$hex.apk")
        if (done.exists() && verify(done, u)) return@withContext UpdateResult.Ready(done)
        done.delete()
        dir.listFiles()?.filter { !it.name.startsWith(hex) }?.forEach { it.delete() } // older updates
        val part = File(dir, "$hex.part")
        val have = (part.length() / CHUNK) * CHUNK
        RandomAccessFile(part, "rw").use { it.setLength(have) }
        var index = (have / CHUNK).toInt()
        try {
            FileOutputStream(part, true).use { out ->
                while (index.toLong() * CHUNK < u.size) {
                    val api = online.current() ?: return@withContext UpdateResult.Offline
                    val c = api.apkGet(u.sha256.toByteArray(), index)
                    out.write(c.data.toByteArray())
                    index++
                    progress((index.toLong() * CHUNK).coerceAtMost(u.size).toFloat() / u.size)
                }
            }
        } catch (e: RpcException) {
            if (e.status == Status.STATUS_NOT_FOUND) return@withContext UpdateResult.NotOnServer
            throw e
        }
        if (!verify(part, u)) { part.delete(); return@withContext UpdateResult.Corrupt }
        part.renameTo(done)
        UpdateResult.Ready(done)
    }

    private fun verify(f: File, u: AppUpdate): Boolean {
        if (f.length() != u.size) return false
        val md = MessageDigest.getInstance("SHA-256")
        f.inputStream().use { s -> val buf = ByteArray(64 * 1024); while (true) { val n = s.read(buf); if (n < 0) break; md.update(buf, 0, n) } }
        return md.digest().contentEquals(u.sha256.toByteArray())
    }

    companion object { const val CHUNK = 1L shl 20 }
}
```
