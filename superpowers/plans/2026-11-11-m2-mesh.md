# M2 — Mesh (2–3 Replicating Nodes) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two or three `otter-node`s hold the same data and keep working through outages and
partial blocking. Apps verify nodes by pinned certificates, follow manifest updates, and connect
to the fastest reachable node.

**Architecture:** Each node keeps its append-only oplog (M0/M1). Nodes open **one symmetric peer
session per pair** over the same TLS port as clients, on `<secret path>/peer`. After a signed mutual
handshake, each side subscribes to the other's oplog from a stored cursor and receives batches
(≤512 records / 4 MiB, ≤4 unacknowledged). Records are re-validated and applied idempotently, then
re-appended to the receiver's own oplog, so they flow on transitively (A→B→C when A↔C is blocked).
Business conflicts on replicated records are resolved deterministically (usernames) or tolerated
(invite reuse). One-time prekey consumption replicates as node-signed `PREKEY_CONSUMED` records.
A janitor expires envelopes, ACKs and tombstones after 30 days and compacts the oplog. Snapshots
are unnecessary: deleted records leave the oplog, so `Since(cursor)` always yields the live set.
Android pins TLS keys from the signed manifest, races endpoints, tracks per-endpoint stats,
follows manifest versions and re-sends undelivered messages after 24 h.

**Tech Stack:** as M1, plus Go `crypto/x509`/`crypto/tls` (cert generation, pinning) and
OkHttp `okhttp-tls` + `mockwebserver3` 5.2.1 (Android tests only).

**Read first:** `docs/09-roadmap.md` → "M1 notes (2026-11-11)": deviations from the M1 plan and the open issues this
plan resolves (lenient replication → Task 4; dev script `--keep` trap → Task 9; `RpcClient` event buffer → Task 12).
**Android build JVM:** run Gradle on **Temurin 21** (Ubuntu's OpenJDK 21 C2 JIT crashed in R8; JDK 25 is unsupported by
Gradle 8.14) — use the same `JAVA_HOME` that M1 used; `gradle.properties` already carries the R8 workaround.

**Specs:** `docs/03-mesh-replication.md`, `docs/05-transport.md`, `docs/11-deployment.md` (D25–D28: port 27443,
self-signed certificates + SPKI pins). This plan updates `docs/03` where the design was simplified (Task 16).
**Where this plan and `docs/03` / `docs/06` differ (no snapshots, one session per pair, retry-later), this plan wins**; Task 16 brings the docs in line.

**Decisions made while planning (recorded in Task 16):**
- Pinning (Go + Android) is part of M2, because node↔node TLS needs it. **M1.5** shrinks to deployment scripts and DNS helpers.
- One session per node pair; if both directions connect, both sides keep the session **dialed by the lower node_id**.
- No snapshot protocol: the oplog only loses rows of deleted records, envelopes and ACKs expire at the same 30 days, so a
  peer with any cursor converges.
- Username clash across a partition: the winner is the lower `(entry created_ms, user_id)`; the loser's username on nodes
  becomes `name#<8 hex>`. No app UI yet (a rename screen comes in M8).
- "Not replicated yet" is **retryable**: an unknown user at login or as a recipient, and missing prekeys, now return
  `STATUS_RETRY_LATER` instead of UNAUTHORIZED/NOT_FOUND.
- Envelope `origin_node` for replicated records = the peer it came from (exact origin tracking is added with push in M5).

**Out of scope:** deploy scripts/DNS helpers (M1.5), groups (M3), push (M5), REALITY (M7), username rename UI and revocation (M8).

```go
package pinning

import (
	"crypto/ecdsa"
	"crypto/elliptic"
	"crypto/rand"
	"crypto/sha256"
	"crypto/subtle"
	"crypto/tls"
	"crypto/x509"
	"crypto/x509/pkix"
	"encoding/pem"
	"errors"
	"fmt"
	"math/big"
	"net"
	"time"
)

var ErrPinMismatch = errors.New("certificate does not match any pinned key")

func SPKIPin(cert *x509.Certificate) []byte {
	h := sha256.Sum256(cert.RawSubjectPublicKeyInfo)
	return h[:]
}

// ClientConfig returns a TLS config for dialing host. With pins, the CA chain is ignored and the
// leaf must match a pin, be valid now and name host. Without pins, normal verification applies.
func ClientConfig(host string, pins [][]byte) *tls.Config {
	cfg := &tls.Config{ServerName: host, MinVersion: tls.VersionTLS12}
	if len(pins) == 0 {
		return cfg
	}
	cfg.InsecureSkipVerify = true // replaced by VerifyConnection below
	cfg.VerifyConnection = func(cs tls.ConnectionState) error {
		if len(cs.PeerCertificates) == 0 {
			return errors.New("no server certificate")
		}
		leaf := cs.PeerCertificates[0]
		now := time.Now()
		if now.Before(leaf.NotBefore) || now.After(leaf.NotAfter) {
			return fmt.Errorf("certificate not valid now (%v – %v)", leaf.NotBefore, leaf.NotAfter)
		}
		if err := leaf.VerifyHostname(host); err != nil {
			return err
		}
		got := SPKIPin(leaf)
		for _, p := range pins {
			if subtle.ConstantTimeCompare(p, got) == 1 {
				return nil
			}
		}
		return ErrPinMismatch
	}
	return cfg
}

// GenerateCert creates a self-signed ECDSA P-256 certificate for hosts and ips.
func GenerateCert(hosts []string, ips []net.IP, validity time.Duration) (certPEM, keyPEM, pin []byte, err error) {
	key, err := ecdsa.GenerateKey(elliptic.P256(), rand.Reader)
	if err != nil {
		return nil, nil, nil, err
	}
	serial, _ := rand.Int(rand.Reader, new(big.Int).Lsh(big.NewInt(1), 127))
	cn := ""
	if len(hosts) > 0 {
		cn = hosts[0]
	}
	tmpl := &x509.Certificate{
		SerialNumber: serial, Subject: pkix.Name{CommonName: cn},
		NotBefore: time.Now().Add(-time.Hour), NotAfter: time.Now().Add(validity),
		KeyUsage: x509.KeyUsageDigitalSignature, ExtKeyUsage: []x509.ExtKeyUsage{x509.ExtKeyUsageServerAuth},
		DNSNames: hosts, IPAddresses: ips, BasicConstraintsValid: true,
	}
	der, err := x509.CreateCertificate(rand.Reader, tmpl, tmpl, &key.PublicKey, key)
	if err != nil {
		return nil, nil, nil, err
	}
	cert, _ := x509.ParseCertificate(der)
	kb, err := x509.MarshalECPrivateKey(key)
	if err != nil {
		return nil, nil, nil, err
	}
	return pem.EncodeToMemory(&pem.Block{Type: "CERTIFICATE", Bytes: der}),
		pem.EncodeToMemory(&pem.Block{Type: "EC PRIVATE KEY", Bytes: kb}), SPKIPin(cert), nil
}
```

```go
func conflictName(name string, userID []byte) string { return name + "#" + hex.EncodeToString(userID[:4]) }

// wins reports whether (createdA, idA) beats (createdB, idB) for a username.
func wins(createdA int64, idA []byte, createdB int64, idB []byte) bool {
	if createdA != createdB {
		return createdA < createdB
	}
	return bytes.Compare(idA, idB) < 0
}

func applyDirectoryEntry(ctx context.Context, tx *sql.Tx, it item, e *pb.DirectoryEntry, created, now int64) error {
	var cur uint64
	err := tx.QueryRowContext(ctx, `SELECT version FROM users WHERE user_id=?`, e.UserId).Scan(&cur)
	exists := err == nil
	if err != nil && !errors.Is(err, sql.ErrNoRows) {
		return err
	}
	if exists && e.Version <= cur {
		return nil // older or same version: stored as a record, users row unchanged
	}
	name, conflict := e.Username, 0
	var owner []byte
	var ownerCreated int64
	err = tx.QueryRowContext(ctx, `SELECT user_id, entry_created_ms FROM users WHERE username=?`, e.Username).Scan(&owner, &ownerCreated)
	switch {
	case errors.Is(err, sql.ErrNoRows) || (err == nil && bytes.Equal(owner, e.UserId)):
	case err != nil:
		return err
	case !it.fromPeer:
		return ErrUsernameTaken
	case wins(created, e.UserId, ownerCreated, owner):
		if _, err := tx.ExecContext(ctx, `UPDATE users SET username=?, username_conflict=1 WHERE user_id=?`,
			conflictName(e.Username, owner), owner); err != nil {
			return err
		}
	default:
		name, conflict = conflictName(e.Username, e.UserId), 1
	}
```

```go
package service

// ApplyReplicated validates and applies a record received from peer `from`.
// Returns ErrRetryLater if the author is not known yet (its directory entry hasn't arrived).
func (s *Service) ApplyReplicated(ctx context.Context, from []byte, rec *pb.Record) (bool, error) {
	body, err := s.validator(nil).Validate(rec)
	switch {
	case errors.Is(err, records.ErrUnknownAuthor):
		return false, fmt.Errorf("%w: %v", ErrRetryLater, err)
	case errors.Is(err, records.ErrExpired):
		return false, nil
	case err != nil:
		return false, invalid(err)
	}
	_, applied, err := s.Store.ApplyReplicated(ctx, rec, body, from)
	if err != nil || !applied {
		return applied, err
	}
	s.afterApply(ctx, body)
	return true, nil
}

func (s *Service) afterApply(ctx context.Context, body *pb.RecordBody) {
	switch body.Type {
	case pb.RecordType_ENVELOPE:
		var e pb.Envelope
		if proto.Unmarshal(body.Payload, &e) == nil {
			for _, r := range e.Recipients {
				s.Notify.Envelope(r.User, r.Device)
			}
		}
	case pb.RecordType_DIRECTORY_ENTRY:
		s.Notify.Directory()
	case pb.RecordType_MANIFEST:
		if changed, err := s.LoadManifest(ctx); err == nil && changed {
			s.Notify.Manifest(s.CurrentManifest().Version)
		}
	}
}

// PublishManifest accepts a network-signed manifest newer than the current one.
func (s *Service) PublishManifest(ctx context.Context, rec *pb.Record) error {
	body, err := s.validator(nil).Validate(rec)
	if err != nil {
		return invalid(err)
	}
	if body.Type != pb.RecordType_MANIFEST {
		return fmt.Errorf("%w: not a manifest", ErrInvalid)
	}
	var m pb.Manifest
	_ = proto.Unmarshal(body.Payload, &m)
	if cur := s.CurrentManifest(); cur != nil && m.Version <= cur.Version {
		return fmt.Errorf("%w: manifest version %d is not newer than %d", ErrConflict, m.Version, cur.Version)
	}
	if _, _, err := s.Store.ApplyFrom(ctx, rec, body, s.NodeID); err != nil {
		return err
	}
	s.afterApply(ctx, body)
	return nil
}
```

```go
const (
	ProtocolVersion = 1
	maxSkew         = 5 * time.Minute
	handshakeTimeout = 10 * time.Second

func readFrame(ctx context.Context, c *websocket.Conn) (*pb.PeerFrame, error) {
	typ, data, err := c.Read(ctx)
	if err != nil {
		return nil, err
	}
	if typ != websocket.MessageBinary {
		return nil, errors.New("peer: text frame")
	}
	f := &pb.PeerFrame{}
	return f, proto.Unmarshal(data, f)
}

func writeFrame(ctx context.Context, c *websocket.Conn, f *pb.PeerFrame) error {
	b, err := proto.Marshal(f)
	if err != nil {
		return err
	}
	return c.Write(ctx, websocket.MessageBinary, b)
}

func nonce() []byte { b := make([]byte, 32); rand.Read(b); return b }

func skewOK(now time.Time, ts int64) bool {
	d := now.Sub(time.UnixMilli(ts))
	return d <= maxSkew && d >= -maxSkew
}

// acceptHandshake runs on the acceptor; returns the authenticated peer node id.
func (r *Replicator) acceptHandshake(ctx context.Context, c *websocket.Conn) ([]byte, error) {
	ctx, cancel := context.WithTimeout(ctx, handshakeTimeout)
	defer cancel()
	n := nonce()
	if err := writeFrame(ctx, c, &pb.PeerFrame{Kind: &pb.PeerFrame_Hello{Hello: &pb.PeerHello{
		ProtocolVersion: ProtocolVersion, NodeId: r.svc.NodeID, Nonce: n, ManifestVersion: r.manifestVersion()}}}); err != nil {
		return nil, err
	}
	f, err := readFrame(ctx, c)
	if err != nil {
		return nil, err
	}
	a := f.GetAuth()
	if a == nil {
		return nil, errors.New("peer: expected auth")
	}
	pub, ok := r.svc.NodeKey(a.NodeId)
	switch {
	case !ok:
		return nil, fmt.Errorf("peer: node %x not in manifest", a.NodeId)
	case bytes.Equal(a.NodeId, r.svc.NodeID):
		return nil, errors.New("peer: connection to self")
	case !skewOK(r.svc.Now(), a.TsMs):
		return nil, errors.New("peer: clock skew")
	case len(a.Nonce) != 32 || !ed25519.Verify(pub, keys.PeerAuthMessage(r.svc.NodeID, n, a.TsMs), a.Signature):
		return nil, errors.New("peer: bad signature")
	}
	ts := r.svc.Now().UnixMilli()
	sig := ed25519.Sign(r.svc.NodeKeyPriv, keys.PeerAuthMessage(a.NodeId, a.Nonce, ts))
	return a.NodeId, writeFrame(ctx, c, &pb.PeerFrame{Kind: &pb.PeerFrame_AuthOk{AuthOk: &pb.PeerAuthOk{TsMs: ts, Signature: sig}}})
}

// dialHandshake runs on the dialer against expected node n.
func (r *Replicator) dialHandshake(ctx context.Context, c *websocket.Conn, n *pb.NodeInfo) error {
	ctx, cancel := context.WithTimeout(ctx, handshakeTimeout)
	defer cancel()
	f, err := readFrame(ctx, c)
	if err != nil {
		return err
	}
	h := f.GetHello()
	if h == nil || !bytes.Equal(h.NodeId, n.NodeId) || len(h.Nonce) != 32 {
		return errors.New("peer: unexpected hello")
	}
	my := nonce()
	ts := r.svc.Now().UnixMilli()
	if err := writeFrame(ctx, c, &pb.PeerFrame{Kind: &pb.PeerFrame_Auth{Auth: &pb.PeerAuth{NodeId: r.svc.NodeID, TsMs: ts, Nonce: my,
		ManifestVersion: r.manifestVersion(),
		Signature: ed25519.Sign(r.svc.NodeKeyPriv, keys.PeerAuthMessage(n.NodeId, h.Nonce, ts))}}}); err != nil {
		return err
	}
	f, err = readFrame(ctx, c)
	if err != nil {
		return err
	}
	if e := f.GetError(); e != nil {
		return fmt.Errorf("peer refused: %s", e.Message)
	}
	ok := f.GetAuthOk()
	if ok == nil || !skewOK(r.svc.Now(), ok.TsMs) ||
		!ed25519.Verify(n.NodePub, keys.PeerAuthMessage(r.svc.NodeID, my, ok.TsMs), ok.Signature) {
		return errors.New("peer: bad auth_ok")
	}
	return nil
}
```

```go
	if err != nil {
		return err
	}
	s.cursor = cur
	go s.writeLoop()
	s.send(&pb.PeerFrame{Kind: &pb.PeerFrame_Subscribe{Subscribe: &pb.PeerSubscribe{Cursor: cur}}})
	started := false
	for {
		f, err := readFrame(s.ctx, s.c)
		if err != nil {
			return err
		}
		switch k := f.Kind.(type) {
		case *pb.PeerFrame_Subscribe:
			if !started {
				started = true
				go s.serve(k.Subscribe.Cursor)
			}
		case *pb.PeerFrame_Batch:
			if err := s.receive(k.Batch); err != nil {
				return err
			}
		case *pb.PeerFrame_BatchAck:
			select {
			case <-s.acks:
			default:
			}
		case *pb.PeerFrame_Error:
			return fmt.Errorf("peer error: %s", k.Error.Message)
		}
	}
}

func (s *session) send(f *pb.PeerFrame) {
	select {
	case s.out <- f:
	case <-s.ctx.Done():
	}
}

func (s *session) writeLoop() {
	for {
		select {
		case f := <-s.out:
			ctx, cancel := context.WithTimeout(s.ctx, 30*time.Second)
			err := writeFrame(ctx, s.c, f)
			cancel()
			if err != nil {
				s.cancel()
				return
			}
		case <-s.ctx.Done():
			return
		}
	}
}

// serve streams our oplog after `from` to the peer.
func (s *session) serve(from int64) {
	cursor := from
	idleSent := false
	for s.ctx.Err() == nil {
		changed := s.r.st.Changed() // take before querying to avoid missing a commit
		entries, err := s.r.st.Since(s.ctx, cursor, maxBatchRecords)
		if err != nil {
			s.r.log.Warn("peer since", "err", err)
			s.cancel()
			return
		}
		if len(entries) == 0 {
			if !idleSent {
				s.send(&pb.PeerFrame{Kind: &pb.PeerFrame_Batch{Batch: &pb.PeerBatch{LastSeq: cursor, CaughtUp: true}}})
				idleSent = true
			}
			select {
			case <-changed:
			case <-s.ctx.Done():
				return
			case <-time.After(time.Minute): // safety net
			}
			continue
		}
		b := &pb.PeerBatch{}
		size := 0
		for _, e := range entries {
			if size+len(e.Raw) > maxBatchBytes && len(b.Records) > 0 {
				break
			}
			b.Records = append(b.Records, e.Raw)
			size += len(e.Raw)
			b.LastSeq = e.Seq
		}
		select {
		case s.acks <- struct{}{}: // take a window slot (released by BatchAck)
		case <-s.ctx.Done():
			return
		}
		s.send(&pb.PeerFrame{Kind: &pb.PeerFrame_Batch{Batch: b}})
		cursor = b.LastSeq
		idleSent = false
	}
}

func (s *session) receive(b *pb.PeerBatch) error {
	for _, raw := range b.Records {
		rec := &pb.Record{}
		if err := proto.Unmarshal(raw, rec); err != nil {
			s.r.log.Warn("peer sent undecodable record", "peer", fmt.Sprintf("%x", s.peer))
			continue
		}
		if _, err := s.r.svc.ApplyReplicated(s.ctx, s.peer, rec); err != nil {
			if errors.Is(err, service.ErrRetryLater) {
				return err // cursor not advanced; redial later re-sends from here
			}
			s.r.log.Warn("peer record rejected", "peer", fmt.Sprintf("%x", s.peer), "err", err)
		}
	}
	if b.LastSeq > s.cursorValue() {
		if err := s.r.st.SetPeerCursor(s.ctx, s.peer, b.LastSeq); err != nil {
			return err
		}
		s.setCursor(b.LastSeq)
	}
	s.mu.Lock()
	s.caughtUp = b.CaughtUp
	s.mu.Unlock()
	if len(b.Records) > 0 {
		s.send(&pb.PeerFrame{Kind: &pb.PeerFrame_BatchAck{BatchAck: &pb.PeerBatchAck{Seq: b.LastSeq}}})
	}
	return nil
}

func (s *session) cursorValue() int64 { s.mu.Lock(); defer s.mu.Unlock(); return s.cursor }
func (s *session) setCursor(c int64)   { s.mu.Lock(); s.cursor = c; s.mu.Unlock() }
```
(`caught_up` batches carry no records and are not acked; they don't use a window slot.)

```go
// add registers s; returns false if s lost the tie-break (caller closes it).
func (g *registry) add(s *session) bool {
	g.mu.Lock()
	defer g.mu.Unlock()
	k := string(s.peer)
	old := g.byPeer[k]
	if old == nil || bytes.Compare(s.dialer, old.dialer) <= 0 {
		if old != nil {
			old.close()
		}
		g.byPeer[k] = s
		return true
	}
	return false
}

func (g *registry) remove(s *session) {
	g.mu.Lock()
	defer g.mu.Unlock()
	if g.byPeer[string(s.peer)] == s {
		delete(g.byPeer, string(s.peer))
	}
}
```

```go
type Replicator struct {

	st     *store.Store
	dialer Dialer
	log    *slog.Logger

func New(svc *service.Service, dialer Dialer, log *slog.Logger) *Replicator {
	r := &Replicator{svc: svc, st: svc.Store, dialer: dialer, log: log, ctx: context.Background(),
		reg: registry{byPeer: map[string]*session{}}, backoff: map[string]time.Duration{}, nextTry: map[string]time.Time{}}
	svc.OnManifest(func(m *pb.Manifest) { r.pruneSessions(m) })
	return r
}

func (r *Replicator) manifestVersion() uint64 {
	if m := r.svc.CurrentManifest(); m != nil {
		return m.Version
	}
	return 0
}

// ServeHTTP accepts peer connections on <path>/peer.
func (r *Replicator) ServeHTTP(w http.ResponseWriter, req *http.Request) {
	c, err := websocket.Accept(w, req, &websocket.AcceptOptions{InsecureSkipVerify: true})
	if err != nil {
		return
	}
	c.SetReadLimit(maxFrame)
	peer, err := r.acceptHandshake(req.Context(), c)
	if err != nil {
		r.log.Info("peer rejected", "remote", req.RemoteAddr, "err", err)
		_ = writeFrame(req.Context(), c, &pb.PeerFrame{Kind: &pb.PeerFrame_Error{Error: &pb.PeerError{Message: "handshake failed"}}})
		c.Close(websocket.StatusPolicyViolation, "handshake failed")
		return
	}
	r.runSession(c, peer, peer) // the remote side dialed
}

func (r *Replicator) runSession(c *websocket.Conn, peer, dialer []byte) {
	s := newSession(r, c, peer, dialer)
	if !r.reg.add(s) {
		c.Close(websocket.StatusNormalClosure, "duplicate session")
		return
	}
	defer r.reg.remove(s)
	r.log.Info("peer session up", "peer", fmt.Sprintf("%x", peer), "dialer", fmt.Sprintf("%x", dialer))
	err := s.run()
	r.log.Info("peer session down", "peer", fmt.Sprintf("%x", peer), "err", err)
	r.mu.Lock()
	k := string(peer)
	if time.Since(s.start) >= time.Minute {
		r.backoff[k] = 0
	}
	if errors.Is(err, service.ErrRetryLater) {
		r.nextTry[k] = time.Now().Add(30 * time.Second)
	}
	r.mu.Unlock()
}

// Run keeps sessions to all manifest peers until ctx ends.
func (r *Replicator) Run(ctx context.Context) {
	r.ctx = ctx
	t := time.NewTicker(5 * time.Second)
	defer t.Stop()
	for {
		r.dialMissing(ctx)
		select {
		case <-ctx.Done():
			return
		case <-t.C:
		}
	}
}

func (r *Replicator) dialMissing(ctx context.Context) {
	m := r.svc.CurrentManifest()
	if m == nil {
		return
	}
	for _, n := range m.Nodes {
		if bytes.Equal(n.NodeId, r.svc.NodeID) || r.reg.has(n.NodeId) {
			continue
		}
		k := string(n.NodeId)
		r.mu.Lock()
		due := time.Now().After(r.nextTry[k])
		if due {
			b := r.backoff[k]
			b = min(max(b*2, 5*time.Second), 5*time.Minute)
			r.backoff[k] = b
			r.nextTry[k] = time.Now().Add(b)
		}
		r.mu.Unlock()
		if !due {
			continue
		}
		go func(n *pb.NodeInfo) {
			c, err := r.dialer.Dial(ctx, n)
			if err != nil {
				r.log.Debug("peer dial failed", "peer", n.Label, "err", err)
				return
			}
			if err := r.dialHandshake(ctx, c, n); err != nil {
				r.log.Info("peer handshake failed", "peer", n.Label, "err", err)
				c.CloseNow()
				return
			}
			r.runSession(c, n.NodeId, r.svc.NodeID)
		}(n)
	}
}

func (r *Replicator) pruneSessions(m *pb.Manifest) {
	keep := map[string]bool{}
	for _, n := range m.Nodes {
		keep[string(n.NodeId)] = true
	}
	r.reg.mu.Lock()
	defer r.reg.mu.Unlock()
	for k, s := range r.reg.byPeer {
		if !keep[k] {
			s.close()
		}
	}
}

type PeerStatus struct {
	Node      []byte
	Connected bool
	CaughtUp  bool
	Cursor    int64
}

func (r *Replicator) Status() []PeerStatus {
	m := r.svc.CurrentManifest()
	if m == nil {
		return nil
	}
	var out []PeerStatus
	for _, n := range m.Nodes {
		if bytes.Equal(n.NodeId, r.svc.NodeID) {
			continue
		}
		ps := PeerStatus{Node: n.NodeId}
		r.reg.mu.Lock()
		if s := r.reg.byPeer[string(n.NodeId)]; s != nil {
			s.mu.Lock()
			ps.Connected, ps.CaughtUp, ps.Cursor = true, s.caughtUp, s.cursor
			s.mu.Unlock()
		}
		r.reg.mu.Unlock()
		out = append(out, ps)
	}
	return out
}
```

```kotlin
package app.ottermsg.core.network

import java.security.MessageDigest
import java.security.cert.CertificateException
import java.security.cert.X509Certificate
import javax.net.ssl.SSLContext
import javax.net.ssl.X509TrustManager

/** Trusts exactly the leaf certificates whose SubjectPublicKeyInfo SHA-256 is pinned (docs/11 D27). */
class PinnedTrustManager(private val pins: List<ByteArray>) : X509TrustManager {
    init { require(pins.isNotEmpty()) }

    override fun checkServerTrusted(chain: Array<X509Certificate>?, authType: String?) {
        val leaf = chain?.firstOrNull() ?: throw CertificateException("empty certificate chain")
        leaf.checkValidity()
        val pin = MessageDigest.getInstance("SHA-256").digest(leaf.publicKey.encoded)
        if (pins.none { MessageDigest.isEqual(it, pin) }) throw CertificateException("certificate does not match the pinned key")
    }

    override fun checkClientTrusted(chain: Array<X509Certificate>?, authType: String?) = throw CertificateException("not supported")
    override fun getAcceptedIssuers(): Array<X509Certificate> = emptyArray()

    fun sslContext(): SSLContext = SSLContext.getInstance("TLS").apply { init(null, arrayOf(this@PinnedTrustManager), null) }
}

fun spkiPin(cert: X509Certificate): ByteArray = MessageDigest.getInstance("SHA-256").digest(cert.publicKey.encoded)
```

- [ ] **Step 2: `NodeSelector.kt`**
```kotlin
class NodeSelector(
    private val transport: Transport, private val stats: EndpointStats, private val clock: () -> Long,
    private val staggerMs: Long = 250, private val maxParallel: Int = 4, private val helloTimeoutMs: Long = 10_000,
) {
    class Winner(val candidate: Candidate, val rpc: RpcClient, val rttMs: Long)

    suspend fun order(cands: List<Candidate>): List<Candidate> {
        val now = clock()
        val withStats = cands.mapIndexed { i, c -> Triple(i, c, stats.get(c.key)) }
        fun group(s: EndpointStat?) = when {
            s != null && now - s.lastFailureMs < 10 * 60_000 && s.lastFailureMs > s.lastSuccessMs -> 2
            s != null && now - s.lastSuccessMs < 7 * 86_400_000L -> 0
            else -> 1
        }
        return withStats.sortedWith(compareBy<Triple<Int, Candidate, EndpointStat?>>({ group(it.third) },
            { if (group(it.third) == 0) it.third!!.rttMs else 0L }, { it.second.priority }, { it.first })).map { it.second }
    }

    /** Returns the first candidate that completes transport + hello, or null if all fail. [scope] owns the winner's RpcClient. */
    suspend fun race(cands: List<Candidate>, scope: CoroutineScope): Winner? = coroutineScope {
        val ordered = order(cands)
        if (ordered.isEmpty()) return@coroutineScope null
        val results = Channel<Pair<Candidate, Winner?>>(Channel.UNLIMITED)
        val gate = Semaphore(maxParallel)
        val jobs = ordered.mapIndexed { i, c ->
            launch {
                delay(i * staggerMs)
                gate.withPermit {
                    val t0 = clock()
                    val w = try {
                        val rpc = RpcClient(transport.connect(c), scope)
                        try { withTimeout(helloTimeoutMs) { rpc.hello.await() }; Winner(c, rpc, clock() - t0) }
                        catch (e: Exception) { rpc.close(); throw e }
                    } catch (e: CancellationException) { throw e } catch (e: Exception) { null }
                    results.send(c to w)
                }
            }
        }
        var winner: Winner? = null
        repeat(ordered.size) {
            val (c, w) = results.receive()
            if (w == null) stats.failure(c.key, clock())
            else if (winner == null) { winner = w; stats.success(c.key, w.rttMs, clock()); jobs.forEach { it.cancel() } }
            else w.rpc.close()
            if (winner != null) return@coroutineScope winner
        }
        null
    }
}
```
(Cancelled jobs that had already connected close their `RpcClient` in the `catch` path; verify with a test that losers' fake connections end closed.)

```kotlin
private suspend fun loop() {
    var backoffMs = 1_000L
    while (scope.isActive) {
        _state.value = ConnectionState.Connecting
        var remaining = candidates()
        var lastError = if (remaining.isEmpty()) "no endpoints" else "unreachable"
        while (remaining.isNotEmpty()) {
            val w = selector.race(remaining, scope) ?: break
            val session = CoroutineScope(scope.coroutineContext + SupervisorJob(scope.coroutineContext[Job]))
            rpc = w.rpc
            try {
                val api = RemoteNodeApi(w.rpc, clock)
                session.onConnected(api)
                _state.value = ConnectionState.Online(api, w.candidate.url, w.candidate.label)
                backoffMs = 1_000L
                w.rpc.closed.await()
                lastError = "connection lost"
                remaining = emptyList()          // session ended normally: back off briefly, then race all again
            } catch (e: CancellationException) { throw e } catch (e: Exception) {
                lastError = e.message ?: e.javaClass.simpleName
                stats.failure(w.candidate.key, clock())
                remaining = remaining - w.candidate // login failed here: try the others now
            } finally { session.cancel(); w.rpc.close(); rpc = null }
        }
        val wait = (backoffMs * (1.0 + (random.nextDouble() - 0.5) * 0.4)).toLong()
        _state.value = ConnectionState.Waiting(clock() + wait, lastError)
        delay(wait)
        backoffMs = (backoffMs * 2).coerceAtMost(60_000)
    }
}
```
