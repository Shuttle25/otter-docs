# M12 Per-chat mute — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every chat — 1:1, group and «Новости Выдры» — can be muted and unmuted on its own; a muted chat posts no
message notifications, calls still ring.

**Architecture:** Purely on the phone. A `muted` column on `conversations` (Room v12), checked first in
`MessageNotifier.onIncoming`. A bell button in every chat's top bar and a long-press menu in the chat list switch it
through `MessageRepository.setMuted`, which also clears a shown notification. Backups carry the flag
(`BackupConversation.muted`, `BackupSnapshot.news_muted`). Nodes are never told.

**Tech Stack:** Kotlin, Jetpack Compose, Room (AutoMigration), Hilt, protobuf, Robolectric + Roborazzi (otter-android);
protobuf/buf generation only (otter-server).

**Spec:** `docs/superpowers/specs/2026-11-26-m12-chat-mute-design.md` (approved 2026-11-26).
**Versions:** app **0.14.0** (versionCode **18**); server stays **0.13.0** (proto copy + generated code only).
**Decision:** **D146** (last used: D145).
**Precondition:** M11 merged into main (`git -C otter-android log origin/main --oneline | grep -m1 "Merge M11"`).
